# 刀口与删结巴

AI 听不到声音。切点好不好，靠电平、对回源、重新转写这几种量法提供证据；但这些都只是证据或线索，**量不了或拿不准的就是「待人耳确认」，不是「通过」**。

文中数字是示例阈值，按你的素材底噪和说话习惯调整。

## 一、两类剪切，分开处理

| | 普通剪切 | 连读微剪 |
| --- | --- | --- |
| 做什么 | 删句、删段、删停顿、删整句重复 | 删结巴、删连着说的重复字 |
| 切点在哪 | 真安静处 | 话音里（本来就没有安静处） |
| 主要验收 | 切点电平落到底噪 | 每刀做接点技术检查 + 人耳逐刀听或按约定抽听 |
| 能否只靠程序放行 | 可以，按事先约定 | 不可以；抽听时要写清实际听了多少刀 |

## 二、普通剪切：切点落在哪

1. **按电平定，不按字时间定。** 词级转写的字时间常偏几百毫秒，从整集稿映射过来的偏得更多，拿它当切点会切掉半个字。在音频能量上找安静处。
2. **真安静＝落到这条录音的底噪。** 两个字之间的局部低谷不算，常常还在话音里。
3. **句子结束看能量，不看转写时间戳。** 句尾轻声、拖音和呼吸落到底噪为止才算说完。切在这之前就是「砍尾字」——最常见、最反复出现的切点问题。
4. **没有真安静处就不在这里切。** 宁可留一点，不硬切；往外让到最近的安静处，让了多少写进说明。
5. **数字静音不算停顿。** 需要补停顿时，用同一素材里电平一致的现场底噪；或者按你的包装约定保持安静（见整集包装）。
6. 英文接缝淡接要短（示例：约 20 毫秒）。
7. 有画面时切点按整帧对齐（见主文件时间映射）。

### 普通剪切出片后怎么验

对**最终交付的那个文件**量（装封面、改字幕之后再量一次）：

- **对回源**：不读你自己的段表，只拿成片声音对回源，逐刀（含第一句起点、最后一句终点）量是否落在安静处。
- **刀口另一边没有字**：没有字被切到另一侧。
- **没有咔哒声、高频跳变**；两侧响度不突跳。
- **空当长度**和这个人平常说话的节奏一致。
- 结果三档：合格；不合格（挪到安静处，没有就不在这里切）；没查完（音乐压着话音、变速、源给错——先查原因；注意带进了被删的字时，程序也常常落到「没查完」而不是「不合格」，要先排除这一种）。量不了的逐条交人工判，写明理由。

已知盲区：刀离字尾极近又加了淡出时量不出；同一句在源里出现两遍可能对错位置；底噪高的素材会多报。

### 只适用于「只删静音」的检查

如果某一步**声称只删了静音或停顿**，可以再筛查：被删掉的区间里最响处比附近话音低很多（示例：20 dB 以上）。这只是**筛查线索**，不能证明区间里没有话音（轻声、气声字可能很弱）；不满足的必须回听，满足的也按风险抽听。这一条**不适用于**删句、删重复、删结巴——那些本来就要删掉话音。

## 三、连读微剪：删结巴

**目的**：听着顺、不奇怪、切口干净、意思一点不变。

### 剪

- 卡住重起：单字或词头卡住（「我我我」「因因为」）。
- 说了半截重说（「我觉得我觉得」）。
- 连接词、代词重复（「但是但是」「这个这个」）。
- 句首当口头禅、去掉不影响意思的「然后」「对吧」。
- 同一个字词连说几遍、意思一样的只留一遍。

### 不剪

1. 两句话交界碰巧同一个字（前句以「我」结尾、后句以「我」开头）——剪了两句粘成一句，意思变了。
2. 叠字词、有意叠说（「谢谢」「看看」「非常非常」）。
3. 应答附和（「对对」「好好好」）。
4. 有意把重点再说一遍（两遍都完整、第二遍不轻、中间没卡）。
5. 句中当连接用的「然后」、表示确认或追问的「对吧」。

**每一刀都读前后整句再定**，不只看重复的那两个字。拿不准的按原样留。

### 怎么做

1. 用程序全片扫候选。**扫的时候用短窗听写**（示例：12 秒一窗），长段听写容易把重复吞掉。
2. 有风险（会伤到旁边的字）的不剪，交付说明里写「扫出 N 处、剪了 M 处、K 处因风险没剪」。
3. 每一刀做接点检查，作为**线索**：
   - 拼接处重新听写，看两边留下的字有没有明显缺失或多出；
   - 有没有咔哒声、高频跳变；
   - 空当是否不自然地短或长；
   - 两边响度有没有突然一跳。
   听写会补全残字，也会漏识别，所以「听写对上」不证明没切伤字。
4. **人耳**：可以逐刀听（剪出每处前后几秒给批准人听），也可以按事先约定抽听。抽听不等于每个切点都有人耳确认过；交付说明如实写「共 N 刀，人耳听了 M 刀，其余只做了技术检查」。

### 字幕和结巴

字幕不改掉声音里真有的字。可约定的例外：结巴只写一遍，「嗯」「啊」不写，声音不动。想从字幕上清掉口头禅，就从声音里删。

## 四、精简主持人自己的重复

主持人说话最常见的问题是**同一内容、同一观点反复说**。长视频、短视频都精剪到说清一遍（这是普通剪切，按第二节定切点）：

- 删整句或半句，删完核上下文连贯。
- **留下有必要或有意义的重复**：总结、强调要点、换个说法让人听懂。
- 拿不准就按这条片要讲的要点判；交付说明写明删了哪几处、留了哪几处、为什么。
- 访谈里同一个追问问了两遍，删第二遍、留第一遍。

## 五、机器粗筛的边界

可以让程序先删明确的几类，再交人逐字精简，并写明程序删了什么：

- 口头禅（如「对吧」「你知道吗」）；
- **起头的**「然后」（句中当连接的不动）；
- 结巴重复（示例：同字 ≥3 遍只留一个；两字词说两遍，两遍之间真有停顿才删）。

**不做语义精简**——哪句啰嗦是编辑判断。两头都连着说的不删、只报告。程序标出的每一处，再按上面的「剪／不剪」过一遍。
