# 示例：一处删减从提议到检查记录

下面的人物、对话、时间全部是虚构的，只用来演示方法。主持人记作「主持人」，嘉宾记作「嘉宾」。

## 1. 原文（源时间为虚构）

```
[12:03.2] 主持人：你当时为什么决定换工作？
[12:05.8] 嘉宾：其实一开始我没想换。我只是周末去面包店帮忙，
[12:10.4] 嘉宾：后来老板说缺人，我就……就想试试。
[12:14.9] 嘉宾：但是我没告诉家里。
[12:17.1] 主持人：那后来呢？
[12:18.0] 嘉宾：后来他们知道了，反对得挺厉害的。可我已经喜欢上凌晨开炉的那种感觉了。
```

## 2. 建议删法（第一稿）

想把这一段压短，提议删掉 12:05.8–12:14.9（「其实一开始……就想试试。」），拼成：

```
主持人：你当时为什么决定换工作？｜嘉宾：但是我没告诉家里。
```

另一条精简建议（如果这一段保留的话）：在 12:13 附近删掉结巴「就……」。

## 3. 为什么不能这样删

- **问答断了**：问题是「为什么换工作」，删完以后回答里一个原因都没有了，只剩「没告诉家里」。
- **承接词悬空**：「但是」原本转折的是「想试试」，前提被删掉，「但是」没有所指。
- **制造了原访谈没有的意思**：拼完听起来像是「换工作的原因是瞒着家里」，这是原话里没有的因果。
- **切点问题**：第一稿把删除段的终点放在「试试」的字时间结束处，按电平看「试」的尾音还没落到底噪，被删的尾音会残留在成片里，接在「但是」前面。

改法：保留原因（12:05.8–12:14.9 不删）；只删结巴「就……」里多出来的那个「就」，这是一刀连读微剪；如果还要压短，删的是别处的整句，而不是这段问答的回答。

## 4. 检查记录（第二稿，版本 v2）

| 项 | 状态 | 证据 | 说明 |
| --- | --- | --- | --- |
| 改动处语义（问答、指代、原意） | PASS | v2 转写第 12:03–12:22 段通读 | 回答保留了原因，「但是」的前提还在 |
| 连读微剪「就……就」 | REVIEW | 接点重新转写、电平图 | 技术检查未见咔哒声和响度跳变；未经人耳，待批准人听这一刀 |
| 普通剪切切点 | 不适用 | — | 第二稿这一段没有普通剪切 |
| 整段回指扫描 | NOT CHECKED | — | 只查了这一段，全片回指扫描还没跑 |

结论：v2 是「审阅候选」（有 NOT CHECKED，且有未解决的 REVIEW），不能写成「检查完成」。
