# 交付报告模板

照抄下面的结构填写。每一项只用这五种状态：**PASS / FAIL / REVIEW / NOT CHECKED / 不适用**。不要写「检查完成」「没问题」「已处理好」「应该可以」这类说法——状态说明一切，原因写在「说明」里。

## 人耳情况

- 连读微剪：共 ___ 刀，人耳听了 ___ 刀，其余只做了技术检查。

## 独立复核

- 经独立复核：是（复核人、日期）／否（写「未经独立复核」）

## 结论（只选一个）

- [ ] 审阅候选：有 FAIL 或 NOT CHECKED，或有未解决的 REVIEW
- [ ] 待批准：全部 PASS 或不适用，没有未解决的 REVIEW，等批准人确认
- [ ] 已批准：批准人原话：「　」；日期：；批准范围（版本、方面）：

只有自动检查确实做完而且都通过、只是还没人听看时，才写「自动检查完成，待听看」；否则按实际状态报告。不写「已处理好」。
